webserv works

Демо-страница для conf/default.conf. Каждая ссылка проверяет одну возможность.

Статика и маршруты

  • GET /about/ → index.html вложенного каталога (200)
  • GET /files/ → autoindex: листинг каталога
  • GET /files/data.json → Content-Type: application/json
  • GET /empty/ → нет index и autoindex off (404)
  • GET /old → 301 на /about/
  • GET /nonexistent.html → своя страница 404

CGI

  • /cgi-bin/hello.py → python3
  • /cgi-bin/env.py/extra/path?name=slava → переменные окружения (PATH_INFO, REMOTE_ADDR) и cwd
  • /cgi-sh/hello.sh → bash
  • /cgi-bin/infinite.py → бесконечный цикл, 504 через 5 с
  • /cgi-bin/crash.py → скрипт упал, 502

Загрузка файлов

multipart-форма:
  • curl -i -F "file=@Makefile" http://localhost:8080/uploads/ → 201, файл Makefile

Загрузка и удаление (curl)

  • curl -i --data-binary @Makefile http://localhost:8080/uploads/Makefile.txt → 201
  • GET /uploads/ → листинг загруженного
  • curl -i -X DELETE http://localhost:8080/uploads/Makefile.txt → 204
  • curl -i -X POST http://localhost:8080/ → 405 + Allow: GET, HEAD
  • curl -i -X PUT http://localhost:8080/ → 501
