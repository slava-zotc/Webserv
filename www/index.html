webserv works

GET / → 200 OK (index_file_ resolved from directory)

resolve_path + Content-Type: text/html

Ручные сценарии для этой страницы:

  • GET / → должен отдать этот файл (200)
  • GET /about/ → должен отдать about/index.html (200)
  • GET /empty/ → index_file_ отсутствует, autoindex выключен → ожидаем 403 или 404 (смотря что решишь)
  • GET /nonexistent.html → 404
