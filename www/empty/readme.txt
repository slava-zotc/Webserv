Эта директория намеренно не содержит index.html.

Используется для ручной проверки ветки в handle_get_method,
когда запрошенная директория существует, но:
  - index_file_ (index.html) внутри неё отсутствует
  - autoindex_ для роута выключен (как в текущем main.cpp)


Проверка вручную:
  curl -i http://127.0.0.1:8080/empty/
